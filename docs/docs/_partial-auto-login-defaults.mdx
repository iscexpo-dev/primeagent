:::note
Official release packages, tagged source archives, and Docker images disable automatic login by default.

For a new Python package installation, do the following:

1. Create a `.env` file with the following values:

```text
PRIMEAGENT_AUTO_LOGIN=false
PRIMEAGENT_SUPERUSER_PASSWORD=REPLACE_WITH_A_STRONG_PASSWORD
```

2. Start Primeagent with the `.env` file:

```bash
uv run primeagent run --env-file .env
```

3. Sign in with the username `primeagent` or your configured `PRIMEAGENT_SUPERUSER`.

For more information, see [`PRIMEAGENT_AUTO_LOGIN`](/api-keys-and-authentication#primeagent-auto-login).
:::
