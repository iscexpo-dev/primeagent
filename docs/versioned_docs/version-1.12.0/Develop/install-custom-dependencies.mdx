Primeagent provides optional dependency groups and support for custom dependencies to extend Primeagent functionality. This guide covers how to add dependencies for different Primeagent installations, including Primeagent Desktop and Primeagent OSS.

The Primeagent codebase uses three package layers:

* The minimal application (`primeagent-base`) is managed at `src/backend/base/pyproject.toml`. As of Primeagent 1.12, it is a complete Primeagent install: UI, API, platform services, built-in components, and the `primeagent` command, without provider extensions. It is version-aligned with `primeagent`, and  depends on `wfx`. There is no `primeagent-core` package.
* The full package (`primeagent`) is managed by the root-level `pyproject.toml`. It depends on the same `primeagent-base` version and adds the curated standalone `wfx-*` provider extensions.
* The `wfx` package is managed at `src/wfx/pyproject.toml`. WFX is a lightweight CLI tool for executing and serving Primeagent flows. The `wfx` package does not provide optional dependency groups for end users.

## Install custom dependencies in Primeagent Desktop {#primeagent-desktop}

To add dependencies to Primeagent Desktop, add an entry for the package to the application's `requirements.txt` file:

    * On macOS, the file is located at `/Users/USER/.primeagent/data/requirements.txt`.
    * On Windows, the file is located at `C:\Users\USER\AppData\Roaming\com.Primeagent\data\requirements.txt`.

Add each dependency to `requirements.txt` on its own line in the format `DEPENDENCY==VERSION`, such as `matplotlib==3.10.0`.

Restart Primeagent Desktop to install the dependencies.

If you need to change or uninstall custom dependencies, edit the `requirements.txt` file, and then restart Primeagent Desktop.

## Install custom dependencies in Primeagent OSS

To install your own custom dependencies in your Primeagent environment, add them with your package manager.

If you're working within a cloned Primeagent repository, add dependencies with `uv add` because there is already a `pyproject.toml` file for uv to reference:

```bash
uv add DEPENDENCY
```

### Install optional dependency groups for `primeagent`

The `primeagent` package (main) provides optional dependency groups that extend its functionality.

By default, installing `primeagent` without any extras includes all dependencies listed in the `[project.dependencies]` section. Optional dependency groups are not installed by default and must be explicitly requested.

These optional dependencies are listed in the [primeagent `pyproject.toml`](https://github.com/khulnasoft-bot/primeagent/blob/main/pyproject.toml) file under `[project.optional-dependencies]`.

Install dependency groups using pip's `[extras]` syntax. For example, to install `primeagent` with the `postgresql` dependency group, enter the following command:

```bash
uv pip install "primeagent[postgresql]"
```

To install multiple extras, use commas to separate each dependency group:

```bash
uv pip install "primeagent[postgresql,audio]"
```

Use the `bundles` extra to install the non-PyTorch providers from `wfx-bundles` plus the
opt-in standalone packages listed in
[Additional bundles](/extensions-bundle-list#additional-bundles):

```bash
uv pip install "primeagent[bundles]"
```

### Install optional dependency groups for `primeagent-base`

`primeagent-base` is the minimal workable Primeagent: the UI, API, platform
services, and built-in components, without provider extensions. It is
version-aligned with `primeagent` starting with version 1.12.0. It includes platform services such as Redis, Chroma, MCP, Kubernetes, object storage, and
tracing support. The `primeagent` package depends on this same version of
`primeagent-base` and adds curated standalone extensions.

The `primeagent-base` package provides its own optional dependency groups that are separate from those in the `primeagent` package. The `primeagent-base` package can be installed as a standalone package with these optional dependency groups.

By default, installing `primeagent-base` without any extras includes all dependencies listed in the `[project.dependencies]` section. Optional dependency groups are not installed by default and must be explicitly requested.
These optional dependency groups are listed in the [primeagent-base `pyproject.toml`](https://github.com/khulnasoft-bot/primeagent/blob/main/src/backend/base/pyproject.toml) file under `[project.optional-dependencies]`.

Install `primeagent-base` with optional dependency groups using pip's `[extras]` syntax. For example, to install `primeagent-base` with the `postgresql` dependency group:

```bash
uv pip install "primeagent-base[postgresql]"
```

To install multiple extras, use commas to separate each dependency group:

```bash
uv pip install "primeagent-base[postgresql,cassandra]"
```

Provider components are installed as extensions. For example, install
`wfx-openai` beside `primeagent-base`, or use `primeagent` to install the curated
provider set:

```bash
uv pip install primeagent-base wfx-openai
```

The base executable is `primeagent`; there is no `primeagent-base` command.

### Use a virtual environment to test custom dependencies

When testing locally, use a virtual environment to isolate your dependencies and prevent conflicts with other Python projects.

For example, if you want to experiment with a custom dependency like `matplotlib` with Primeagent:

```bash
# Create and activate a virtual environment
uv venv YOUR_PRIMEAGENT_VENV
source YOUR_PRIMEAGENT_VENV/bin/activate

# Install primeagent and your additional dependency
uv pip install primeagent matplotlib
```

You can also install `primeagent-base` with specific optional dependency groups in your virtual environment:

```bash
# Install runnable base with selected compatibility extras
uv pip install "primeagent-base[postgresql,cassandra]" matplotlib
```

If you're working within a cloned Primeagent repository, add dependencies with `uv add` to reference the existing `pyproject.toml` files:

```bash
uv add matplotlib
```

The `uv add` command automatically updates the `uv.lock` file in the appropriate location.

## Add dependencies to the Primeagent codebase

When contributing to the Primeagent codebase, you might need to add dependencies to Primeagent.

To add a dependency to the `main` package, run `uv add DEPENDENCY` from the project root.
For example:

```bash
uv add matplotlib
```

Dependencies can be added to the `main` package as regular dependencies at `[project.dependencies]` or optional dependencies at `[project.optional-dependencies]`.

To add a dependency to the `base` package, navigate to `src/backend/base` and run:
```bash
uv add DEPENDENCY
```

To add a development dependency for testing, linting, or debugging, navigate to `src/backend/base` and run:
```bash
cd src/backend/base && uv add --group dev DEPENDENCY
```

Dependencies can be added to the `base` package as regular dependencies at `[project.dependencies]`, development dependencies at `[dependency-groups.dev]`, or optional dependencies at `[project.optional-dependencies]`.

You can optionally use `make add` instead of `uv add`:

```bash
# Equivalent to: uv add matplotlib
make add main="matplotlib"

# Equivalent to: cd src/backend/base && uv add --group dev matplotlib
make add devel="matplotlib"

# Equivalent to: cd src/backend/base && uv add matplotlib
make add base="matplotlib"
```

Alternatively, you can add these dependencies manually to the appropriate `pyproject.toml` file:

```
[project]
dependencies = [
    "matplotlib>=3.8.0"
]
```

Or as an optional dependency in the main package:

```
[project.optional-dependencies]
plotting = [
    "matplotlib>=3.8.0",
]
```

Or as a development dependency in the base package:

```
[dependency-groups]
dev = [
    "matplotlib>=3.8.0",
]
```
