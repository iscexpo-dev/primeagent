This page lists every official Primeagent bundle and the pip **extension** package that ships it.
Bundle names are stable identifiers used in saved flows (`ext:<bundle>:<Class>@official`).
The pip install command is what you run when a bundle is missing from your environment.

This list reflects the bundles included with Primeagent 1.13.0.
Providers can graduate from `wfx-bundles` to a standalone `wfx-<provider>` package without changing the bundle name in your flows.

## Providers in `wfx-bundles` {#wfx-bundles}

These providers do not have their own `wfx-<provider>` package.

To install one provider and its SDK, run `uv pip install "wfx-bundles[<bundle-name>]"`.
To install every provider in `wfx-bundles`, run `uv pip install "wfx[bundles]"`.

To install every provider, including providers that require PyTorch as a dependency, run `uv pip install "wfx-bundles[all]"`.
