## Prerequisites

* [Install and start Primeagent](/get-started-installation) with the developer API enabled

    The Workflow API endpoints require the `developer_api_enabled` setting to be enabled. If this setting is disabled, these endpoints will return a 404 Not Found error.

    To enable the developer API endpoint, do the following:
    1. In the Primeagent `.env` file, set the environment variable to `true`:
       ```
       PRIMEAGENT_DEVELOPER_API_ENABLED=true
       ```
    2. Start your Primeagent server with the `.env` file enabled:
       ```
       uv run primeagent run --env-file .env
       ```

    For more information about configuring environment variables, see [Environment variables](/environment-variables).
* [Create a Primeagent API key](/api-keys-and-authentication)
* [Create a flow](/concepts-flows) that you want to execute
* [Get the flow ID](/concepts-publish#api-access) or endpoint name of the flow you want to execute

### Set environment variables

All code examples in this documentation assume you have set the following environment variables:

**Python:**
```python
import os

PRIMEAGENT_SERVER_URL = os.getenv("PRIMEAGENT_SERVER_URL")
PRIMEAGENT_API_KEY = os.getenv("PRIMEAGENT_API_KEY")
```

**TypeScript/JavaScript:**
```typescript
const PRIMEAGENT_SERVER_URL = process.env.PRIMEAGENT_SERVER_URL;
const PRIMEAGENT_API_KEY = process.env.PRIMEAGENT_API_KEY;
```

Set these environment variables before running the examples, or replace the variable references in the code examples with your actual Primeagent server URL and API key.

The default `PRIMEAGENT_SERVER_URL` for a local Primeagent deployment is `http://localhost:7860`.
For remote deployments, the domain is set by your hosting service, such as `https://UUID.ngrok.app`.

### Authentication and headers

All Workflow API requests require authentication using a Primeagent API key. The API key is passed in the `x-api-key` header.

For more information, see [Create a Primeagent API key](/api-keys-and-authentication).

| Header | Description | Example |
|--------|-------------|---------|
| `Content-Type` | Specifies the JSON format. | `application/json` |
| `x-api-key` | Your Primeagent API key. | `sk-...` |
| `accept` | Optional. Specifies the response format. | `application/json` |
